段取りの司令塔

始まる前に、勝負を決めている

直感 決め方 根拠

根拠 · 材料を揃えて決める

単独 進め方 巻き込み

巻き込み · 人と組んで進める

前倒し 締切 追い込み

前倒し · 早めに終わらせる

仕切る 立ち位置 支える

仕切る · 前に出て決める

情報を集め、人を配置し、前倒しで進める。最も破綻の少ない進め方をする、組織の中でいちばん強いタイプです。

段取りが完璧すぎて、まわりが考えるのをやめています。

強み

  • 計画の精度が高い
  • 人と情報の両方を動かせる
  • リスクを事前に潰せる

気をつけたいこと

  • 周囲が指示待ちになりやすい
  • 自分の計画から外れる案を受け入れにくい

力が出る環境

規模の大きい案件、複数チームの統括、責任範囲の広い管理職。

自己PRのたたき台

関係者と情報を事前に整理して計画を組み立て、リスクを潰した状態で実行してきました。

面接やエントリーシートにそのまま置ける一文にしてあります。自分の経験に合わせて書き換えて使ってください。

面接の備え

「短所は？」への答え方

  • 材料を集めすぎて、判断が遅れることがありました。今は調べ始める前に、決める日を先に決めています。
  • 人に相談しすぎて、自分で考える時間が減ることがありました。今はまず自分の案を出してから相談しています。
  • 余裕がある前提で計画を立てがちでした。今は必ず予備日を入れるようにしています。
  • 自分で決めたくなり、意見を聞く前に動くことがありました。今は先に一周、意見を聞くようにしています。

あなたが突かれる質問

  • 「情報が足りない場面では、どう決めますか？」 → 決めきれずに機会を逃した経験と、そこから変えたことをセットで話す
  • 「自分ひとりで成し遂げたことはありますか？」 → 巻き込んだ話の中で、自分が担った部分をはっきり切り出す
  • 「予定が崩れたとき、どうしましたか？」 → 計画通りにいかなかった経験を、必ず1つ用意しておく
  • 「周囲と衝突したことはありますか？」 → 引っ張った話には、反対意見をどう扱ったかを必ず入れる

ガクチカで厚く書くところ

  • 「なぜそうしたか」の根拠部分。ここを書ける人は多くない
  • 動かした人数と、どう動かしたか。数字を入れると効く
  • 準備の段階。ここを書ける学生は少なく、差がつく
  • 決めた場面と、その結果。判断そのものを書く

短所は、自覚と対策をセットにすると通ります。丸暗記せず、自分の経験に置き換えてから使ってください。

ここまで掘られます

決め方 — 根拠

  1. 情報が足りないときは、どう決めますか？
  2. 決めきれなかったことはありますか？
  3. そのとき、何を失いましたか？

崩れない答え方

「特にありません」が一番危険です。失ったものを具体的に言えると、誠実さと学習能力が同時に伝わります。

進め方 — 巻き込み

  1. 自分ひとりで成し遂げたことはありますか？
  2. 周りに頼らず、どこまでやりましたか？
  3. なぜ、そこは人に頼らなかったのですか？

崩れない答え方

「頼れなかった」と言うと弱く聞こえます。「ここは自分がやるべきだと判断した」に変えるだけで、主体性の話になります。

締切 — 前倒し

  1. 予定通りにいかなかった経験はありますか？
  2. そのとき、最初に何をしましたか？
  3. なぜ、それを最初にやったのですか？

崩れない答え方

3段目で問われているのは優先順位の付け方です。「何を捨てたか」まで言えると、判断力の証明になります。

立ち位置 — 仕切る

  1. 周囲と意見が割れたことはありますか？
  2. そのとき、相手の意見はどう扱いましたか？
  3. 結果的に、あなたの判断は正しかったですか？

崩れない答え方

3段目で「正しかったです」と言い切ると、独断的に映ります。取り入れた部分を1つ挙げてから結果を話すと、同じ話が協調性の証明に変わります。

面接官は同じ話を3回掘ります。学生が崩れるのは2段目と3段目です。ここを先に用意しておくと、落ちません。

企業の見極め方

合う環境の条件

  • 数字と根拠で判断する習慣が、実際に回っている
  • チームで進めるのが前提で、相談しやすい距離にいる
  • 計画が守られる前提があり、急な差し込みが少ない
  • 若手にも早い段階で決定権が渡る

説明会・面接で聞くこと

「施策がうまくいったかどうかは、何で判断していますか？」

返ってきた答えの読み方

○「毎週この指標を見ています」と具体的な数字が出る

△「感覚ですね」と笑われた → 根拠で語る文化はない

×数字を1つも言えない → あなたの武器が評価されない

「ひとつの仕事は、普段どれくらいの人数で進めますか？」

返ってきた答えの読み方

○「常に2〜3人で見ています」と具体的な人数が出る

△「基本は個人ですが相談はできます」→ 実態は一人の可能性

×「席も離れていて各自で進めます」→ 巻き込む余地が少ない

「予定が急に変わることは、どれくらいの頻度でありますか？」

返ってきた答えの読み方

○「四半期の計画がほぼそのまま動きます」

△「臨機応変が売りです」→ 前倒しが無駄になる可能性

×繁忙期の話をはぐらかされた → 一番聞きたいところを避けている

「入社して何年目から、自分で決められるようになりますか？」

返ってきた答えの読み方

○「1年目から自分の判断で動いてもらいます」

△「人によります」→ 実例を1つ聞く。答えられなければ実績がない

×「まずは3年、しっかり学んでもらいます」→ 決める機会は当分ない

合わないサイン

  • 「まずやってみよう」しか出てこない。数字が答えられない
  • 基本は個人プレー。誰が何をしているか見えない
  • 繁忙期の話をはぐらかされた。「臨機応変」を連呼する
  • 年次の話が多い。決裁が上に集中している

そのまま逆質問に使えます。答えを聞いて、自分に合うかを自分で判断してください。合う・合わないは会社の良し悪しではありません。
