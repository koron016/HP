直感 決め方 根拠

直感 · 感覚で決める

単独 進め方 巻き込み

巻き込み · 人と組んで進める

前倒し 締切 追い込み

前倒し · 早めに終わらせる

仕切る 立ち位置 支える

支える · 後ろから支える

感覚で場の空気を読み、人と動き、早めに準備しておく。仕切るというより、みんなが動きやすいように整えておく人です。

自分の仕事だけが、いつも最後に残ります。

強み

  • 全体の段取りが自然に見えている
  • 人が動きやすい状態を作れる
  • 抜け漏れに先に気づく

気をつけたいこと

  • 人の仕事を引き受けすぎる
  • 自分の成果が後回しになる

力が出る環境

複数の人と部署をまたぐ仕事。進行管理、運営、コーディネーター的な役割。

自己PRのたたき台

関係者が多い場面で全体の段取りを整え、それぞれが動きやすい状態を先に作ってきました。

面接やエントリーシートにそのまま置ける一文にしてあります。自分の経験に合わせて書き換えて使ってください。

面接の備え

「短所は？」への答え方

  • 勘で動きすぎて、根拠を求められると詰まることがありました。今は決める前に、理由を一度書き出すようにしています。
  • 人に相談しすぎて、自分で考える時間が減ることがありました。今はまず自分の案を出してから相談しています。
  • 余裕がある前提で計画を立てがちでした。今は必ず予備日を入れるようにしています。
  • 意見はあっても、言い出すのが遅れることがありました。今は会議で必ず一度は発言すると決めています。

あなたが突かれる質問

  • 「その判断に、根拠はありましたか？」 → 勘で決めた場面でも、後から言葉にできる理由を1つ用意しておく
  • 「自分ひとりで成し遂げたことはありますか？」 → 巻き込んだ話の中で、自分が担った部分をはっきり切り出す
  • 「予定が崩れたとき、どうしましたか？」 → 計画通りにいかなかった経験を、必ず1つ用意しておく
  • 「自分から動いた経験を教えてください」 → 支えた話の中から、自分の判断で動いた瞬間を1つ切り出す

ガクチカで厚く書くところ

  • 動き出しの速さが武器。「なぜすぐ動けたのか」を厚く書く
  • 動かした人数と、どう動かしたか。数字を入れると効く
  • 準備の段階。ここを書ける学生は少なく、差がつく
  • 支えた相手がどう変わったか。相手の変化で書くと伝わる

短所は、自覚と対策をセットにすると通ります。丸暗記せず、自分の経験に置き換えてから使ってください。

ここまで掘られます

決め方 — 直感

  1. その判断の根拠は何でしたか？
  2. 他の選択肢は検討しましたか？
  3. なぜ、その選択肢を捨てたのですか？

崩れない答え方

捨てた理由を1つ言えれば通ります。「考えませんでした」は避け、「〜だと判断して外しました」と、選ばなかったことも判断として語ってください。

進め方 — 巻き込み

  1. 自分ひとりで成し遂げたことはありますか？
  2. 周りに頼らず、どこまでやりましたか？
  3. なぜ、そこは人に頼らなかったのですか？

崩れない答え方

「頼れなかった」と言うと弱く聞こえます。「ここは自分がやるべきだと判断した」に変えるだけで、主体性の話になります。

締切 — 前倒し

  1. 予定通りにいかなかった経験はありますか？
  2. そのとき、最初に何をしましたか？
  3. なぜ、それを最初にやったのですか？

崩れない答え方

3段目で問われているのは優先順位の付け方です。「何を捨てたか」まで言えると、判断力の証明になります。

立ち位置 — 支える

  1. 自分から動いた経験を教えてください
  2. それは、誰かに言われて始めたことですか？
  3. 言われる前に動けなかったのは、なぜですか？

崩れない答え方

「様子を見ていました」は受け身に聞こえます。「動く条件が揃うのを待っていた」「先に周りの状況を確かめていた」と、待つことを判断として語ってください。

面接官は同じ話を3回掘ります。学生が崩れるのは2段目と3段目です。ここを先に用意しておくと、落ちません。

企業の見極め方

合う環境の条件

  • 決裁の階層が浅く、速く動けることが評価される
  • チームで進めるのが前提で、相談しやすい距離にいる
  • 計画が守られる前提があり、急な差し込みが少ない
  • 役割がはっきりしていて、専門性を積み上げられる

説明会・面接で聞くこと

「何かを決めるとき、だいたいどれくらいで結論が出ますか？」

返ってきた答えの読み方

○「その場で決まることが多いです」

△「案件によりますね」→ はぐらかし。「直近の例だと？」と重ねる

×「稟議を通すので2週間ほど」→ あなたの速さは活きない

「ひとつの仕事は、普段どれくらいの人数で進めますか？」

返ってきた答えの読み方

○「常に2〜3人で見ています」と具体的な人数が出る

△「基本は個人ですが相談はできます」→ 実態は一人の可能性

×「席も離れていて各自で進めます」→ 巻き込む余地が少ない

「予定が急に変わることは、どれくらいの頻度でありますか？」

返ってきた答えの読み方

○「四半期の計画がほぼそのまま動きます」

△「臨機応変が売りです」→ 前倒しが無駄になる可能性

×繁忙期の話をはぐらかされた → 一番聞きたいところを避けている

「配属後は、どんな役割から始まりますか？」

返ってきた答えの読み方

○役割の名前と担当範囲がすぐ出てくる

△「いろいろ経験してもらいます」→ 何屋になるのか見えない

×「なんでもやってもらいます」→ 専門性は積み上がらない

合わないサイン

  • 稟議の話が長い。「前例がないと難しい」と言われた
  • 基本は個人プレー。誰が何をしているか見えない
  • 繁忙期の話をはぐらかされた。「臨機応変」を連呼する
  • 「なんでもやってもらう」と言われた。役割の説明が曖昧

そのまま逆質問に使えます。答えを聞いて、自分に合うかを自分で判断してください。合う・合わないは会社の良し悪しではありません。
