# AI16タイプ診断

8つの質問に答えると、AIとの付き合い方が **16タイプ**のどれかに分かれる診断サイトです。
MBTIと同じように4文字のタイプ名（例：`DQCP`）が出て、相性のいいタイプもわかります。

HTML・CSS・JavaScript だけで動くので、**サーバー代も維持費もかかりません**。

---

## 4つの軸

| 軸 | マイナス側 | プラス側 |
|---|---|---|
| 任せ方 | **S** 自走（自分でやる） | **D** 委任（AIに任せる） |
| 受け取り方 | **Q** 検証（まず疑う） | **T** 信頼（まず信じる） |
| 話しかけ方 | **O** 指示（用件だけ） | **C** 対話（相談するように） |
| 見せ方 | **H** 秘匿（言わない） | **P** 公言（話す） |

この4文字の組み合わせで 2×2×2×2＝**16タイプ**になります。

---

## ファイルの役割

| ファイル | 中身 |
|---|---|
| `assets/quiz-data.js` | **質問と16タイプの文章。直すのはほぼここだけ** |
| `index.html` | 診断の画面 |
| `assets/quiz.js` | 診断の動き（さわらなくて大丈夫） |
| `assets/style.css` | 見た目と色 |
| `result/*.html` | タイプごとのページ 16枚（自動生成） |
| `assets/ogp/*.png` | Xでシェアされたときに出る画像 17枚（自動生成） |
| `tools/build.js` | 上2つを作り直すスクリプト |

`index.html` をダブルクリックすれば、そのまま手元で試せます。

## 中身を書き換える

`assets/quiz-data.js` を開いてください。質問も16タイプの文章も、すべてこのファイルにあります。

### 大事な注意が2つ

**1. 書き換えたら、必ずこれを実行する**

```bash
node tools/build.js
```

結果ページとシェア画像が作り直されます。忘れると、サイトの表示とXでシェアされた内容がズレます。

> シェア画像も作り直す場合は `npm install playwright` が必要です。
> 入れていない場合は、画像を飛ばして結果ページだけ作り直します。

**2. 点数の付け方には決まりがある**

各軸は2問ずつで、**1問目は奇数（±1, ±3）、2問目は偶数（±2, ±4）**にしてあります。
こうすると合計が必ず奇数になり、**0（引き分け）になりません**。0になるとタイプが決まらないためです。

この決まりを崩すと `node tools/build.js` がエラーを出して止まります。点検が入っているので、
壊れたまま公開されることはありません。

## インターネットに公開する（無料）

GitHub Pages を使います。お金はかかりません。

1. GitHub で `koron016/HP` を開く
2. 上のタブの **Settings** → 左メニューの **Pages**
3. **Source** を `Deploy from a branch` にする
4. **Branch** で `claude/claude-md-docs-3bgn2h` を選び、フォルダは `/ (root)` のまま
5. **Save**

数分待つと、このアドレスで公開されます。

```
https://koron016.github.io/HP/
```

> **公開先を変える場合**は、`assets/quiz-data.js` の先頭にある `siteUrl` を書き換えてから
> `node tools/build.js` を実行し直してください。シェア画像のアドレスがここから作られています。

## 拡散のしくみ

このサイトは「シェアされること」を前提に作ってあります。

- **4文字のタイプ名は、名乗れる肩書きになります。**「私はDQCP」と言えることが、
  ％だけの診断との決定的な違いです
- **タイプごとに専用ページと専用画像**があるので、Xでシェアされるとそのタイプの画像が出ます
- **相性のいいタイプ／話が合わないタイプ**が出るので、友達と見せ合う理由が生まれます
- 相性の相手はリンクになっていて、押すとそのタイプのページに飛べます
- シェア文にはタイプ名と**ハッシュタグ `#AI16タイプ診断`** が自動で入ります

### 広めるときのコツ（調査で分かったこと）

- **自虐が入っている結果ほどシェアされます**（全タイプに一言入れてあります）
- 「はい / いいえ」だけの極端な二択は伸びません（全問4択）
- **宣伝色が出るとテンションが下がって離脱**します

## 動作について

- スマートフォン優先で作ってあります
- キーボードの `1`〜`4` でも回答できます
- 診断はJavaScriptで動くため、無効だと使えません（その旨のメッセージが出ます）
