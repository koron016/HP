# ホームページ

koron のホームページです。HTML と CSS だけで作ってあるので、**サーバー代も維持費もかかりません**。

- `index.html` … ページの中身（文章はここ）
- `assets/style.css` … 見た目・色
- `assets/main.js` … スクロールの演出、配色の切り替え

---

## まず見てみる

`index.html` をダブルクリックすればブラウザで開けます。それだけで確認できます。

---

## 文章を書き換える

`index.html` をテキストエディタで開くと、こういう目印が入っています。

```html
<!-- ▼ 書き換えポイント：名前・肩書き・ひとこと -->
```

この目印のすぐ下を書き換えれば OK です。書き換えたら保存して、ブラウザで再読み込み（F5）すれば反映されます。

書き換えポイントは4か所あります。

| 場所 | 何を直すか |
|---|---|
| サイト左上 | 表示する名前 |
| ヒーロー | 名前・キャッチコピー |
| 自己紹介 | 紹介文、できること |
| つくったもの | 作品の紹介 |
| 連絡先 | SNS リンク |

### 色を変えたい

`assets/style.css` の一番上に色の設定がまとまっています。`--accent` を好きな色コードに変えると、
ボタンやリンクの色が一括で変わります。

```css
--accent: #c4553d;   /* ここを変えると全体の差し色が変わります */
```

### 作品を増やしたい

`index.html` の「つくったもの」の中にある `<article class="work reveal">` から `</article>` までを
まるごとコピーして、下に貼り付けて中身を書き換えてください。

## インターネットに公開する（無料）

GitHub Pages を使います。お金はかかりません。

1. GitHub で `koron016/HP` を開く
2. 上のタブの **Settings** をクリック
3. 左のメニューから **Pages** を選ぶ
4. **Source** を `Deploy from a branch` にする
5. **Branch** で `claude/claude-md-docs-3bgn2h` を選び、フォルダは `/ (root)` のまま
6. **Save** を押す

数分待つと、このアドレスで公開されます。

```
https://koron016.github.io/HP/
```

公開したあとは、ファイルを直して push するたびに自動で更新されます。

> **メモ**：このリポジトリには `main` ブランチがありません。そのため手順5でブランチを自分で
> 選ぶ必要があります。将来このホームページを `main` ブランチに移せば、選ばなくてもよくなります。

## 動作について

- スマートフォンでも見られるようにしてあります
- 端末がダークモードなら自動で暗い配色になり、右上のボタンで手動でも切り替えられます
- JavaScript が動かない環境でも、文章はすべて読めます
