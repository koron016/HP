# AI依存度診断

6つの質問に答えると、自分がどこまでAIに頼っているかが％で出る診断サイトです。
HTML・CSS・JavaScript だけで動くので、**サーバー代も維持費もかかりません**。

---

## ファイルの役割

| ファイル | 中身 |
|---|---|
| `assets/quiz-data.js` | **質問と結果の文章。直すのはほぼここだけ** |
| `index.html` | 診断の画面 |
| `assets/quiz.js` | 診断の動き（さわらなくて大丈夫） |
| `assets/style.css` | 見た目と色 |
| `result/*.html` | 結果ごとのページ（自動生成） |
| `assets/ogp/*.png` | Xでシェアされたときに出る画像（自動生成） |
| `tools/build.js` | 上2つを作り直すスクリプト |

`index.html` をダブルクリックすれば、そのまま手元で試せます。

---

## 中身を書き換える

`assets/quiz-data.js` を開いてください。質問も結果の文章も、すべてこのファイルにあります。

```js
{
  q: "調べものがあるとき、最初に開くのは。",
  choices: [
    { text: "検索エンジン", points: 0 },
    ...
  ]
}
```

`points` は「依存度の高さ」の点数です。全部の質問の点数を足して、結果が決まります。

### 大事な注意

**質問や点数を変えたら、必ず次のコマンドを実行してください。**

```bash
node tools/build.js
```

結果ページとシェア画像が作り直されます。これを忘れると、サイトの表示と、
Xでシェアされたときの内容がズレます。

> シェア画像も作り直す場合は `npm install playwright` が必要です。
> 入れていない場合、画像は飛ばして結果ページだけ作り直します。

### 結果の数を変えたいとき

`results` の `min` と `max` が合計点の範囲です。**すき間ができないように**つなげてください。
（例：`0〜2` の次は `3〜5`）満点は現在 18点です。

## 拡散のしくみ

このサイトは「シェアされること」を前提に作ってあります。

- **結果ごとに専用のページと専用の画像**があります。Xでシェアされると、その人の結果に合った
  画像が出ます（全員同じ画像より、押される率がかなり変わります）
- シェア文には結果と**ハッシュタグ `#AI依存度診断`** が自動で入ります
- シェアされたリンクを開いた人には「自分も診断してみる」ボタンが出るので、
  **見た人がまた診断して、またシェアする**流れになります

### 広めるときのコツ（調査で分かったこと）

- 質問は **4〜6問が最適**。10問以上は途中でやめる人が増えます（今は6問）
- **自虐が入っている結果ほどシェアされます**
- 「はい / いいえ」だけの極端な二択は伸びません（今は4択）
- **宣伝色が出るとテンションが下がって離脱**します

## 動作について

- スマートフォン優先で作ってあります
- キーボードの `1`〜`4` でも回答できます
- 診断はJavaScriptで動くため、無効だと使えません（その旨のメッセージが出ます）
